# MLCASim

## About MLCASim
ML based Circuit Simulation for Analog Circuit Array.

POSTECH CSDL and LG Display (2022-2024)

## Usage
To use MLCASim, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/csdl-projects/MLCASim.git
    ```

2. Install the required dependencies:
    ```bash
    # For python version 3.11.9
    pip install -r requirements.txt
    ```

3. Run the simulation and ML based training and inference:
    Follow env_setting.pdf

## Features
- ML based circuit simulation
- Support for analog circuit arrays
